Funcionamento:

Inicialmente o cli, ao ser executado mostra uma saudação na tela, por exemplo:

Dentro da pasta dartpedia em home/seu.diretorio/dartpedia/cli rode o comando

'dart run bin/cli.dart search blahblahblahblah'

(O "blahblahblahblah" pode ser qualquer artigo do existe dentro da Wikipedia)


Obs. Importante! Este aplicativo esta em desenvolvimento e ao longo do tempo o comportamento pode mudar.
